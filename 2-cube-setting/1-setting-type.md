# 2.1 큐브 영역 설정 방법  
큐브의 설정 방법은 2가지로 제공됩니다.

### 2.1.1 대각점 설정방법   
![](../_assets/diag_pints2.png)

- 큐브의 대각 위치 두 점을 설정합니다. 대각의 시작위치와 종료위치를 직접 입력합니다.  
- 현재 로봇의 TCP 위치로 기록하려면 <시작위치> 혹은 <종료위치>에 커서를 놓고 `현재 로봇 포즈` 버튼을 누르면 현재의 위치로 기록할 수 있습니다.  
- 설정 예  
![](../_assets/cube_diag_points.png)


### 2.1.2 중심점 설정방법  
![](../_assets/center_point2.png)

- 큐브의 중심점과 X방향, Y방향, Z방향 거리를 각각 설정하는 방식입니다.  
- 큐브 영역의 중심점 위치를 기록하고 중심점으로 부터 X, Y, Z 방향에 대한 거리를 각각 설정 합니다. 
- 중심점을 현재 로봇의 TCP 위치로 기록하려면 <중심위치>에 커서를 놓고  `현재 로봇 포즈` 버튼을 누르면 현재의 위치로 기록할 수 있습니다.  
- 설정 예  
  ![](../_assets/center_point.png)
